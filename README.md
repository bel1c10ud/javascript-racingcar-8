# javascript-racingcar-precourse

## 구현할 기능 목록

- [x] 사용자 입력 받기
- [x] 입력받은 자동차 이름 구분자로 나누기
- [x] 자동차 이름 검증하기
  - [x] 1자 이상인지 검증하기
  - [x] 5자 이하인지 검증하기
  - [x] 이름이 중복되지 않는지 검증하기
- [x] 입력받은 시도 횟수 타입 변환하기
- [x] 시도 횟수 검증하기
  - [x] 숫자인지 검증하기
  - [x] 양수인지 검증하기
  - [x] 정수인지 검증하기
- [x] 시도 횟수만큼 전진 여부 구하기
- [x] 매 회마다 결과 값 출력하기
- [x] 최종 우승자 출력하기
- [x] 리팩토링
- [ ] 테스트 코드 작성
